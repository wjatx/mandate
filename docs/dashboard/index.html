The tapes are hash-chained, so editing, dropping, or reordering any record breaks every hash after it. shim_refusals.jsonl is an ordinary log with no integrity claim: those refusals happen inside the admitted connector, so the broker sees a tool returning a result rather than a decision of its own. The audit chain is unkeyed SHA-256. Verification proves the tape is self-consistent — no record was edited, dropped, or reordered in place. It is not tamper-proof: anyone who can write the file can rewrite it whole and recompute every hash. Tamper-evidence needs off-device append-only storage.
